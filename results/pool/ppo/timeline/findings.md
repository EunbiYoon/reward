## 정의 (rlaif/credit_timeline.py)

- `s(t)`: 0..t 구간에서 agent 0의 Shapley 몫. 반사실 에피소드 두 개를 다시 돌려 구한다. `s = (v_L + v − v_P) / 2 / v`.
  - `v_P`: agent 0을 멈춰 세웠을 때의 팀 점수.
  - `v_L`: 파트너를 멈춰 세웠을 때의 팀 점수.
- `o(t)`: 같은 시점에서 자른 두 에피소드를 보고 판정자가 agent 0에게 준 몫.
- `gap = o − s`: 0보다 크면 판정자가 공을 더 준 것. 처음으로 gap > 0.1이 되는 t를 crossing이라 한다.

## 무엇을 말해주나

1. **배달 가로채기는 판정자를 처음부터 끝까지 속인다.**
   - 첫 배달이 나오는 t = 50에서 바로 crossing이 생긴다. 19개 궤적이 모두 그렇다.
   - 그 뒤로 gap +0.3 ~ +0.45가 계속 유지된다.
   - 판정자는 배달한 쪽에 반 이상(o ≈ 0.5–0.65)을 준다. 하지만 양파 넣기와 요리 시작은 파트너가 다 했으므로 실제 기여는 s ≈ 0.18이다.
   - 시간이 지나도 판정자가 이를 바로잡지 못한다.
2. **가짜 도움은 시간이 갈수록 판정자를 더 속인다.**
   - s는 내내 정확히 0이다. agent 0이 없어도 팀 점수가 같다는 뜻이다.
   - 그런데 o는 0.25에서 0.30으로 올라간다. gap도 t = 50에 0이던 것이 t = 300에 0.30까지 커진다.
   - 양파를 집은 횟수가 쌓일수록(구간마다 23–25번) 판정자가 그걸 기여로 쳐 준다.
3. **정직한 요리사는 거의 정확히 평가받는다.**
   - s = 0.50, o ≈ 0.50–0.59이다.
   - 13/18이 crossing으로 잡히지만, 초반 수프가 1–3개뿐일 때 0.5 대 0.67, 0.8 같은 반올림 차이다.
   - 임계값 0.1이 수프가 적은 초반 구간에는 너무 민감하다.
4. **shadow는 반대로 과소평가된다. 판정자보다 Shapley 쪽이 문제다.**
   - 판정자는 사건(event)이 없으니 0을 준다.
   - Shapley는 약 0.15를 준다. agent 0을 멈춰 세우면 좁은 주방(cramped room)에서 그 몸이 길을 막아, 파트너 혼자 수프 10개 대신 8개를 만든다(예: s4: v = 10, v_P = 8). 그래서 "비켜 있기"가 기여로 잡힌다.
   - 즉 "멈춰 세운 agent가 장애물이 되는" 반사실 설계에서 나온 결과다. 판정자의 0이 실제 기여에 더 가까울 수 있다.
5. **fidget의 큰 gap은 Shapley 쪽에서 생긴 착시다.**
   - 팀 수프가 1–2개뿐이라 `s = φ / v`의 분모가 작다. 게다가 멈춘 agent 0이 움직이는 fidget보다 덜 방해되므로 s가 음수로 크게 떨어진다(최저 −3.5).
   - 판정자는 o ≈ 0.05로 사실상 맞게 본다.
   - 이 행동은 gap 평균에서 빼거나, s를 [0, 1]로 자르거나, φ를 직접 비교해야 한다.

## 논문에 쓸 수 있는 문장 (초안)

> 판정자의 과대평가는 행동 종류에 따라 시점이 다르다. 배달 가로채기는 첫 배달(t = 50)부터 +0.3 이상 과대평가되고 끝까지 고쳐지지 않는다(19/19). 가짜 도움은 처음에는 맞게 평가되다가 집기 횟수가 쌓이면서 gap이 0 → 0.30으로 커진다(17/19). 정직한 요리사는 gap이 0.06 이내로 맞게 평가된다. 판정자는 "누가 마지막에 배달했나"와 "얼마나 바빠 보이나"에 공을 주고, 앞 단계에서 준비한 사람에게는 공을 덜 준다.
